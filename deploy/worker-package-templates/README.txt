========================================================================
                  Worker Agent 节点使用说明指南
========================================================================

【首次运行与自动注册】
1. 确认已配置 worker.toml 中的 [storage].nas_mount（NAS挂载路径）。
2. 启动 Worker：
   - Windows 系统：直接双击运行「一键启动Worker.bat」
   - macOS 系统  ：直接双击运行「一键启动Worker.command」
   - Linux 系统  ：终端执行「./start-worker.sh」
3. 首次启动时，Worker 会自动向云端 Master 主控发起注册，并在控制台显示「等待管理员审核」。
4. 管理员登录云端 Web 管理后台（节点管理页），点击「批准接入」。
5. Worker 收到批准通知后，会自动领取证书与访问令牌，并进入「在线就绪」状态开始接收下载任务！

【注意事项】
- 压缩包内自带经过安全校验的 GOST 代理转发运行时（gost / gost.exe），请保持与 worker-agent 同级存放。
- 节点的证书和私钥会自动保存在 data/ 目录中，请勿随意删除。
- 如需更换设备重新注册，可在控制台禁用旧节点后，删除本地 data/ 目录重新启动。
