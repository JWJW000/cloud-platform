## 2. R 项实施记录

### R0 测试门禁
- `REQUIRE_TEST_DATABASE=1` 无数据库时测试必失败（原有行为验证）；
- 前端接入 Vitest + happy-dom + @vue/test-utils，`npm test` 输出真实用例数（14）；
- `.github/workflows/ci.yml`：rust-static / rust-unit / postgres-integration / frontend / dependency-audit / worker-platform（三 OS 矩阵）/ docker-build；
- 修复了被真实数据库暴露的 4 个既有测试缺陷（`batch_cancel` 的 limit=1、FK 节点缺失、`result_idempotency` 的 NAS 路径硬编码、`session_allocation`/`task_claim_concurrency` 的会话与 NAS 前置条件）。

### R1 静态资源
- `web_root` 统一为镜像内 `/app/web-admin/dist`；配置了但缺失时启动失败；
- 自定义 SPA 回退：真实文件优先、`/api/*` 返回 JSON 404、前端路由回退 `index.html`、哈希资源长期缓存；
- `.dockerignore` 阻止 node_modules/target/密钥进镜像；Dockerfile 只复制 dist；
- 新增 `/health/live`、`/health/ready`（迁移+数据库+配置三查）。

### R2 TLS/mTLS
- Worker 注册通道只接受 HTTPS、系统根/`server_ca_file` 校验、不加载 Node CA、无客户端证书；
- `worker-agent run` fail-closed：endpoint HTTPS、身份/证书/私钥存在、cert/key 匹配、未过期、私有 CA 存在；
- 指纹改为对证书 **DER** 计算；注册产物临时文件+备份+原子切换；
- Caddyfile 拆分为 `ADMIN_DOMAIN`（注册/API/静态）与 `WORKER_DOMAIN`（仅 OpenLink，`require_and_verify` mTLS），清洗并注入真实指纹头。

### R3 NAS no-replace
- 删除 `exists()+rename()` 与忽略锁创建结果的回退；Linux `renameat2`、macOS `renamex_np`、Windows `MoveFileExW`（不带 REPLACE）、硬链接独占创建为兜底；都不支持返回 `Unsupported` → 节点「存储异常」；
- 启动时/重挂载后能力探测（`probe_nas_capability`），心跳合并探测结论；
- 路径安全：canonical 最近父目录 containment、拒绝符号链接最终路径、Windows 保留设备名。

### R4 Worker 重启恢复
- protobuf 新增 `ExecutionStage` / `ReconcileAction` 枚举，禁止自由字符串裁决（中文展示唯一映射在 `platform-proto::display`）；
- SQLite 现场扩充：stage_enum、format、local_file_path、source_size、result_event_id、node_id、created_at；
- 心跳与上线共用 `merged_active_executions`（SQLite 现场 + 内存合并）；
- Worker 对五种裁决显式处理并回逐执行 `ReconcileAck`；未知裁决=协议错误断开重连；Master 收齐 ACK 后才下发 complete。

### R5 事务一致性
- `submit_result` 统一事务：`FOR UPDATE` 锁行 → 同事务读上下文/重裁决 → CAS 条件更新 → `rows_affected==1` 校验 → 提交后发事件；
- 成功/失败/取消各自 CAS；Backfill 只在任务无活动租约（待确认/待处理）时允许；
- 精确取消：`CancelTask` 携带 node/session/task/execution/stage_version，Worker 全字段匹配才取消；
- 批次迁移校验：待开始/执行中/已暂停可取消，已取消幂等，已完成拒绝。

### R6 NAS 证据闭环
- 领取时写入 `expected_nas_relative_path/file_name/format`；
- 不确定结果进入「待确认」时在同一事务固化 `expected_size_bytes/expected_sha256/evidence_*`（只固化一次）；
- 核验只使用已固化期望：缺路径=数据错误告警、缺 SHA 不得自动判完成、缺大小不得把未知当匹配；
- 哈希/大小/路径不符保持待确认并严重告警；文件缺失回待处理。

### R7 认证与会话
- 登录响应 Cookie-only（`admin_session`，HttpOnly+Secure+SameSite=Lax），不再返回 JWT；
- 强制 jti UUID、会话存在且未撤销、`session.user_id==sub`、token_hash 常量时间比较；任意失败 401；
- 限流：全局容量上限、定期清理、指数退避；成功只清理用户名计数；
- `X-Forwarded-For` 仅信任 `trusted_proxies` 网段；CSRF Origin 校验中间件；
- JWT secret ≥32 字节且拒绝示例弱密钥。

### R8 代理转发
- 用 hyper 1.x + hyper-util 重写本地代理：CONNECT 隧道 + 普通 HTTP 转发；
- framing（Content-Length/chunked/close-delimited/HEAD/204）全部由 hyper 处理；
- 客户端伪造 `Proxy-Authorization` 被替换；连接关闭时统一回收子任务。

### R9 Webshare 完整快照
- 超过分页上限/任一页异常/重定向/响应超限/重复 external_id → 放弃整个同步，数据库不变；
- 同步世代（`sync_generation`）标记快照归属；只停用旧世代且本次未出现的代理；
- 已占用失效代理 `retire_after_release`；冷却到期但 provider 已失效的代理不得复活；
- `(provider, external_id)` 部分唯一索引。

### R10 部署与验收
- docker-compose 健康顺序（postgres→master→caddy）、内部端口、非 root 卷权限、健康检查改 `/health/live|ready`；
- `.env.example`、部署与运维指南（公网/私有 CA 两种方式、NAS 挂载与能力探测、备份回滚）；
- 迁移 `0003_v4_consistency.sql`：users.updated_at、证据 CHECK、token_hash 索引、external_id 唯一、sync_generation 索引、中文枚举 CHECK、历史回填；
- 新增 `tests/migrations.rs` 验证迁移幂等与约束生效。
